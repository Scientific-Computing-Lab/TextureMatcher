# Inventory: claims, notebooks and data files

This inventory is a read-only triage. Nothing in `notebooks_raw/`, `data/` or `paper/` was moved, renamed, edited or executed. Every value check below comes from a read-only Python read of a CSV, JSON, npy or npz file under `data/`, or from the saved cell outputs of a notebook. KID and FID were recomputed from cached features where no summary file holds them.

Conventions:
- `data/` means the results archive on Google Drive. It is `BASE` or `/content/drive/MyDrive/DATA_ROOT` in notebook code.
- "cell N" is the 0-based cell index in the `.ipynb`, counting markdown cells.
- **traceable to file** means the value sits in a CSV/JSON/npz under `data/`, or can be recomputed exactly from cached features there.
- **printed only** means the value appears in a saved cell output but no file under `data/` holds it.
- **unverified** means neither a file nor a saved output reproduces it.

## 0. Findings the reviewer should read first

1. **The main-text tables are all traceable to files.** That covers Table 1, the equal-sample table and the generative table. The ΔKID intervals are in `data/jackknife/jackknife_final.csv`, `jackknife_dKID.csv` and `tm1000_jackknife.csv`.
2. **The trace-corrected absolute KIDs used in the paper are not stored in any file.** These are every `\GKID*`, `\TMKID*`, `\EqKID*`, `\GEKID*` and `\TMkKID*` value. `jackknife_dKID.ipynb` cell 5 and `presubmission_additions.ipynb` cell 6 only print them. They reproduce exactly from `data/jackknife/feats_*.npy` and `data/evidence/ref_inc.npy`. The KID columns of `table120_final.csv` and `table200_final.csv` still hold the old reference-term values, which are 0.000245 higher.
3. **Table 1's Gaussian row exists only as printed output.** It comes from `finish_day.ipynb` cell 10, with FID/KID re-verified from `matching_ablation/feat_gaussian_w2_inc.npy`. `numbers_final128.json` lists the broken `gaussian_ot` map instead (FID 334.0).
4. **Table 1's CNT images are not bit-reproducible.** `tm_scale1000_headtohead.ipynb` cell 7 rendered them with an unseeded `torch.randperm`. Seeding via `_sub(N, seed=pair_id, tag)` starts with `matching_ablation.ipynb`.
5. **`tab:app-position` comes from `position_estimator_4_9.ipynb` (29 July).** That run fed CNT images in [0,1] rather than [-1,1]. `corrected_pipeline_rerun.ipynb` fixed this on 3 August; the uncorrected run kept about 24% of source contrast versus 92% after the fix. The table was not rerun after the fix.
6. **Several supplement tables exist only as printed notebook output.** These are:
   - the Vacher FID column (`ot_direction_fid_barycenter.ipynb` cell 20);
   - `tab:app-realism` (`Vortex.ipynb`);
   - `tab:app-representation` (`cnt sam dino comapre.ipynb` and `never gonna give you up.ipynb`; the file `item2_representation_n40.json` is not in the archive);
   - `tab:app-position`;
   - the order table's Vacher rows, which are **unverified** because no file or output matches them.
7. **The runtime table mixes protocols.** Its caption says 120 pairs under one protocol. The Vacher entry, `\VacherWSec` 52.4 s, comes from the 20-pair run in `paper_completion/timing_n20.csv`. `\GPTsec` 36 s differs from the run report's 38.5 s median. The 128 px timings (`\DecSecLow`, `\OTsecLow`, `\OTInterpSecLow`) are printed only, because `timing_120_ours128.csv` is missing.
8. **`\EqBalP` = 10⁻¹⁴ and `\EqGapP` = 10⁻¹³ are too strict by one order of magnitude.** The paper states p below these values. The recomputed p-values are 1.7·10⁻¹⁴ and 9.5·10⁻¹³.
9. **104 of the 337 macros are defined but never used in the tex.** These include the old 1,000-pair observer block, the correspondence-regime study, the round-trip and large-path macros, OT-sym and the old timing aliases. The full list is in §1D. The package does not need to reproduce them.
10. **Figure provenance stops at the candidate stage.** Candidates are in `data/paper_figs/`, `data/paper_figs_day2/` and `data/paper_completion/figs/`. No notebook writes the final figure names, such as `qualitative_main_cnt.png` or `epsilon_sweep.png`. `paper/` contains no image files, so the final picks cannot be matched by checksum. The only exception is `alignment_progression.png`.

### 4b. The KID reference term

The kernel is `k(a,b) = (a·b/d + 1)^3`, and its diagonal is not 1: the mean is 1.689 on `ref_inc`. Subtracting `len(REF)` from the kernel sum therefore overstates the reference self-term. KID rises by a constant **+0.0002445**, which cancels in every ΔKID.

| Form | Where (notebook · cell) |
|---|---|
| `KYY=(K.sum()-len(REF))/(n(n-1))` (old) | `finishing_experiments` c6 (TM coupling scores) · `jackknife_dKID` c3, c4 (so `table120_final.csv` and `table200_final.csv` KID columns) · `mechanism_study (1)` c14, c18 · `CNT_correspondence_experiments` c14 (`summary.json`) · `CNT_joint_basis_and_ceiling` c3, c5 (`ceiling_summary.json`) |
| `K_ref=kk(REF,REF); KYY=(K_ref.sum()-np.trace(K_ref))/(n(n-1))` (**canonical**) | `jackknife_dKID` c5 (prints every corrected macro, writes nothing) · `presubmission_additions` c6 (`tm1000_*`) · `finishing_experiments` c10 audit (`finishing_audit/*_corrected.csv`, `audit_report.json`) · `ours_vs_tm_distance` c5 (non-canonical reference) |
| Subsampled reference with `np.trace(kyy)` on each draw | `kid()` in every setup cell from F2 onward; used for Table 1 and `tab:rules`, so those were never affected |

The Table 1 and `tab:rules` KIDs are unaffected. The ceiling and primitive KIDs are affected by at most 0.0003, below rounding.

### 4c. Canonical setup used by the package

Take the **F4 cell as it appears in `jackknife_dKID` c1**, with these changes:
1. Replace the KID helpers with one estimator. It caches `K_ref` once, uses the `np.trace(K_ref)` reference term, zeroes the generated-set diagonal, and exposes `kid_point` and `kid_loo` (delete-one terms for the paired jackknife). This is the `presubmission_additions` c6 form.
2. Keep `sinkhorn_plan` (100 iterations, ε=0.05, float32) as the default solver. Keep `sinkhorn_log` (float64, tolerance 1e-3 on marginals) for the equal-sample and Texture Mixer ablations, because the paper uses both.
3. Keep `_sub(N, seed=pair_id, tag)` with `_TAG={'s':1,'t':2}` and `n_exact=1024` with seed `pair_id+11`. Keep the Gaussian ridge at 1e-4 and the NN extension.
4. Pin CNT to `07269302…`, fp32, deterministic cuDNN, TF32 off.
5. Keep the **direct-resize pyramid** (`sm_from_field`) as the default, because every paper row was produced with it. Expose the staged pyramid from `finishing_experiments` c10 as an option.
6. Keep `SCORE_RES=128`, the frozen reference (`evidence/ref_list.json`, `ref_inc.npy`, `ref_dino.npy`), and realism as the median of 5 manifolds with k=3 and n=1000.
7. Drop the F1 unseeded `interp_ot`. Table 1's cached PNGs stay the record, and the score-only mode reads them.
